SETTING TRXP — Mouse / Keyboard

Class Driver · Registry

นำเข้า MouseDataQ.reg และ KeyboardDataQ.reg ที่คุณให้มา โดยบันทึกค่าปัจจุบันก่อนแก้ไข ต้องรีสตาร์ตเพื่อให้ค่า Driver มีผล

NETWORK

Network Adapter Optimizer

ปรับ Receive/Transmit Buffers ของอะแดปเตอร์ที่กำลังเชื่อมต่อ เฉพาะค่าที่ไดรเวอร์รองรับ โดยสำรองค่าเดิมก่อนและคืนค่าได้จากปุ่ม Restore การเชื่อมต่ออาจหลุดชั่วคราว

⚙

SETTING TRXP — Network Latency

Advanced Adapter + TCP/IP

ตั้ง Interrupt Moderation, Energy Efficient/Power Saving และ Flow Control เป็น Disabled เมื่อไดรเวอร์รองรับ พร้อมปรับค่า TCP global ตามรายการที่ให้มา สำรองค่าก่อนทำงาน

ϟ

TRXP Power Plan

Gaming Performance

สร้างหรือเปิดแผน TRXP จาก Balanced ตั้ง CPU min 5% / max 100%, Active Cooling และลองใช้ค่าประสิทธิภาพเสริมเมื่อ Windows รองรับ

▦

RAMMap / Memory

Microsoft Sysinternals

เปิด RAMMap สำหรับตรวจสอบการใช้หน่วยความจำ หรือทดลองล้าง Standby List เมื่อแก้ปัญหาเฉพาะหน้า ไม่แนะนำให้ล้างเป็นประจำ

⌁

Cleaner

Temporary Files

↶

Restore Center

Saved Original Values

คืนค่าจากไฟล์สำรองที่ BY TRXP สร้างไว้ก่อนเปลี่ยนเท่านั้น หากไม่มีสำรอง โปรแกรมจะไม่เดาค่า Windows เดิมให้เอง

⏻

Dashboard Session

Local Web Host

ปิดตัวเชื่อม Local Web Dashboard เมื่อใช้งานเสร็จ หน้าเว็บควรถูกเปิดผ่านปุ่มเริ่มโปรแกรม ไม่ใช่เปิดเป็นไฟล์ HTML โดยตรง

⚠
อ่านก่อนใช้: Driver REG ของคุณมี ThreadPriority=31 ซึ่งสูงมากและอาจกระทบเสถียรภาพ ต้องมี backup และแนะนำให้รีสตาร์ตหลังใช้; ล้าง Standby List ไม่ได้เพิ่ม RAM จริง; Power Plan และการล้าง Cache ไม่รับประกัน FPS/Ping ที่ดีขึ้น
